小白 3 步唤醒控制台

1

定位游戏根目录

Steam 库右键游戏 ➔ 管理 ➔ 浏览本地文件

2

配置底层开关或插件

Bethesda Creation 引擎原生自带控制台： 1. 快捷键：游戏中随时按下键盘左上角【~】键 (波浪键 / ESC下方) 暂停并呼出全屏控制台； 2. 输入法避坑：若无反应，请在 Windows 任务栏切换为'英语(美国)'美式键盘输入法，或在 Documents/My Games/Skyrim Special Edition/Skyrim.ini 的 [General] 下确认 bAllowConsole=1； 3. 防闪退：想减少意外闪退，可以装 SSE Engine Fixes，它修了一批引擎层面的问题，但不能保证完全不闪退。 4. 简写技巧：FormID 开头的 0 可以全部省略，比如金币的 FormID 是 0000000F，player.additem 0000000F 10000 可以写成 player.additem f 10000。

🛠️ 必备优化 CURATED MODS

解决痛点 · 精选 Mod

Skyrim Script Extender (SKSE64) 14.8M 下

扩展 Papyrus 脚本引擎功能的工具，是许多高级 UI 与功能类 Mod 的前置。

SSE Engine Fixes (skse64 plugin) 30.4M 下

SKSE64 插件，用于修复引擎相关问题，包括高帧率下的物理异常、口型不同步、部分内存泄漏与崩溃问题；可选配置在使用 Mod 时仍启用 Steam 成就。

SkyUI 26.6M 下

为 PC 玩家优化界面的 Mod，提供物品列表排序/搜索、分类收藏夹，以及 MCM（Mod 配置菜单）等功能。
